# Task 5 — Decision Trees & Random Forests (AI & ML Internship)

This project focuses on implementing **Decision Tree** and **Random Forest** models using the Heart Disease dataset.  
You will learn:

- How a decision tree works  
- Visualizing a decision tree  
- Avoiding overfitting using max_depth  
- Building a Random Forest  
- Feature importance  
- Cross-validation evaluation  

## 📌 Dataset
You can use any dataset. Recommended: **Heart Disease Dataset (Kaggle)**

## 📁 Project Files
- app.py  
- requirements.txt  
- report.md  
- toolsused.md  

## ▶️ How to Run
pip install -r requirements.txt  
python app.py
